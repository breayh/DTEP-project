# DTEP project - Iron Safety Alarm
A school project featuring an Arduino-based control and monitoring system designed for precise position tracking and time-based alerts for an iron user to prevent fire hazards caused by leaving the iron in horizontal position for too long.

For this project, my role was to write the core Arduino C++ code to power the system's logic and hardware integration. My contributions included implementing a manual calibration routine to set target reference positions, programming an automated timer triggered by stable horizontal orientation detection, and integrating a buzzer alarm that activates when the elapsed time exceeds a pre-defined operational threshold.
